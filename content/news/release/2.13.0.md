[Paraunit 2.13.0](https://github.com/facile-it/paraunit/releases/tag/2.13.0) has just been released with support for a new coverage report format: `--jsonl`, which mirrors PHPUnit's `--coverage-jsonl` option. It writes `coverage.jsonl` and `tests.jsonl` files inside the specified directory and requires `phpunit/php-code-coverage` 14.4 or newer.


This is the full changelog:

* Add `--jsonl` coverage report format, mirroring PHPUnit's `--coverage-jsonl` option (requires `phpunit/php-code-coverage` 14.4+) [#425](https://github.com/facile-it/paraunit/pull/425)
* Add `--timeout`, `--cache-test-index` and `--do-not-cache-test-index` to the options allowed with `--pass-through` [#425](https://github.com/facile-it/paraunit/pull/425)
